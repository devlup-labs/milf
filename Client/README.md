# MILF Client

Client application for the MILF project, built with Vite, React, TypeScript, and Tailwind CSS.

## Getting Started

### Prerequisites

- Node.js
- npm

If you need Node.js, install it with [nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

### Environment Variables

Copy the example env file and update values as needed:

```sh
cp .env.example .env
```

Used variables:

- `VITE_API_BASE_URL` (defaults to `http://localhost:8080`)
- `VITE_GOOGLE_CLIENT_ID`

### Install

```sh
npm install
```

### Development

```sh
npm run dev
```

### Build

```sh
npm run build
```

### Preview

```sh
npm run preview
```

### Test

```sh
npm run test
```

### Lint

```sh
npm run lint
```

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
